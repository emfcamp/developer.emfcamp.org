---
title: Programmable voice
---

Unfortunately we are not running Jambonz this year, so programmable voice will be a bit more work to do.

You can still connect your own SIP server up to the phones system, so you can develop your own integrations this way.

If you are only looking to have a number play a sound, and then hang up - you can still do this using the `APP` number type in the number management.

If your idea is really cool, come and speak to the phones team to see what we can do!
